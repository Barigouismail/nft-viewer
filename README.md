# NFT Viewer

## Description
This project allows users to view their NFTs using a Web3 integration.

## Requirements
- Node.js
- Infura or Alchemy project URL
- ABI of your NFT contract

## Installation
1. Clone this repository.
2. Run `npm install`.
3. Replace `YOUR_INFURA_PROJECT_ID` and `0xYourNFTContractAddress` with your own values in `index.js`.
4. Start the server with `npm start`.

## How It Works
1. Users provide their wallet address.
2. The server fetches and displays their NFTs.
